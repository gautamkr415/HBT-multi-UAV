# HBT-multi-UAV

This code accompanies the manuscript **"Hierarchical Binary Tree-Based Coordination for Multi-UAV Traversal through a Gap"** (Manuscript ID: 2025-12-G009851),
submitted to the AIAA Journal of Guidance, Control, and Dynamics. It is provided
for review purposes.

## Scope

This repository implements the **HBT construction** described in Section III of the
manuscript: the greedy plane-partitioning warm start (Algorithm 1) and the genetic
algorithm that minimizes the path cost (Eq. (9)) to produce the final HBT. 

## Requirements

- MATLAB R2023b
